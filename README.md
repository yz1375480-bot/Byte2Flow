
# Byte2Flow

## Byte2Flow: Packet-Aware Encrypted Traffic Classification for Consumer IoT Gateway Monitoring

This repository accompanies our manuscript, **"Byte2Flow: Packet-Aware Encrypted Traffic Classification for Consumer IoT Gateway Monitoring"**, prepared for submission to *IEEE Transactions on Consumer Electronics*.

## Overview

Byte2Flow is a packet-aware deep learning framework designed for encrypted traffic classification and consumer IoT gateway monitoring. It aims to identify application services and malware families using passively observed packet information, particularly when encryption limits access to application-layer content.

The framework combines multi-scale convolutional feature extraction, metadata-conditioned feature-wise linear modulation (FiLM), and Mamba-based sequence modeling. By jointly learning local byte patterns, packet transmission characteristics, and inter-packet dependencies, Byte2Flow supports traffic identification at consumer-network gateways and associated edge systems.

## Datasets

Two publicly available datasets are used to evaluate Byte2Flow across heterogeneous traffic and encrypted communication scenarios.

### 1. USTC-TFC2016

**USTC-TFC2016**, provided by the University of Science and Technology of China, contains traffic from ten benign applications and ten malware families, covering 20 categories.

The benign portion includes consumer communication and Internet services such as FaceTime, Skype, Gmail, Outlook, BitTorrent, and World of Warcraft, alongside file-transfer and network-service traffic.

USTC-TFC2016 is widely used in encrypted and malicious traffic classification research. Its diverse application protocols and communication patterns provide a benchmark for packet-aware traffic identification in consumer-network environments.

This dataset is used for baseline comparisons, input-configuration selection, and ablation studies.

### 2. DoH-DGA-Malware-Traffic-HKD

**DoH-DGA-Malware-Traffic-HKD (HKD)** contains 4,212 flows generated by four DGA-based malware families:

- PadCrypt
- Sisron
- Tinba
- Zloader

The dataset was collected in a controlled environment during DNS-over-HTTPS (DoH) communications, where HTTPS/TLS encryption protects DNS message contents.

HKD is used to evaluate fine-grained malware-family classification under encrypted DNS communication. Byte2Flow uses observable packet characteristics and communication patterns without requiring payload decryption.

The four malware families are treated as separate classification categories.

Together, USTC-TFC2016 and HKD provide complementary evaluations of heterogeneous traffic identification and encrypted malware communication analysis, supporting gateway-side traffic monitoring in consumer networks.
