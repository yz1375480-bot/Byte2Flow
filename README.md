# Byte2Flow
# Byte2Flow: Packet-Aware Encrypted Traffic Classification for Gateway-Based Monitoring

This repository accompanies our manuscript, **"Byte2Flow: Packet-Aware Encrypted Traffic Classification for Gateway-Based Monitoring"**, which is currently under review.

## Overview

Byte2Flow is a packet-aware deep learning framework designed for communication behavior analysis and gateway-based network monitoring. It aims to identify different network activities and potential security threats using passively observed packet information, particularly in environments where encrypted communications limit the visibility of application-layer content.

## Datasets

Two publicly available datasets are used to evaluate Byte2Flow under different communication conditions.

### 1. USTC-TFC2016

**USTC-TFC2016**, provided by the University of Science and Technology of China, contains communication records from ten benign applications and ten malware families, covering 20 categories.

This dataset is used to evaluate the identification of different communication behaviors through packet-level observations. It provides a heterogeneous network environment for examining the contributions of local byte patterns, packet metadata, and inter-packet dependencies to network activity characterization.

USTC-TFC2016 is also used for baseline comparisons, ablation studies, and model configuration analysis.

Since a substantial portion of this dataset is unencrypted, we treat it as a heterogeneous communication benchmark rather than a dedicated encrypted-traffic dataset.

### 2. DoH-DGA-Malware-Traffic-HKD

**DoH-DGA-Malware-Traffic-HKD (HKD)** contains 4,212 communication flows generated by four malware families:

- PadCrypt
- Sisron
- Tinba
- Zloader

The dataset was collected during DNS-over-HTTPS (DoH) communications, where HTTPS/TLS encryption protects DNS payload contents.

HKD provides a complementary scenario for evaluating communication monitoring under restricted payload visibility. It is used to investigate whether packet-level observations and inter-packet dependencies can distinguish different malware communication behaviors without accessing decrypted application content.

The four malware families are treated as separate classification categories.

Together, these two datasets allow us to evaluate Byte2Flow across heterogeneous and encrypted communication environments.
